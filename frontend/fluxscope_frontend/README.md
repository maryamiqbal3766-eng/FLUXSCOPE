# TADBIR Frontend — Updated Premium UI

This package replaces the previous TADBIR frontend visual foundation.

## Design direction
- Warm cream / ivory editorial background
- Deep burgundy + forest + sage accents
- Elegant serif English headings (stylish, refined, not flashy)
- Clean sans-serif body/interface text
- Custom TADBIR geometric mark with **TADBIR / تدبیر**
- English / Urdu toggle
- Scroll-driven DETECT → TRACE → QUANTIFY → SIMULATE → COMPARE → RESPOND → MONITOR journey
- Truthful empty/awaiting states; no invented economic or financial figures
- UI-only scenario controls until the backend deterministic engine is connected

## Replace the old frontend
1. Delete `D:\Maryamm\TADBIR\frontend\TADBIR_frontend`
2. Extract this ZIP so the new folder is exactly `D:\Maryamm\TADBIR\frontend\TADBIR_frontend`
3. Do not replace or delete `D:\Maryamm\TADBIR\app`, `docs`, or `tests`.

## Vercel
Deploy only the `TADBIR_frontend` folder with Vercel Drop. Do not deploy the whole TADBIR project. No Groq key is included.

## Local run
Node.js/npm is required: `npm install` then `npm run dev`.
